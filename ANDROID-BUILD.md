# Tools Android app

This Android project packages the Tools web interface inside an Android WebView. The app shell is native Android, while the current tool screens are HTML/CSS/JavaScript rather than fully native Compose views.

## Build APK and AAB on GitHub

1. Open the repository's **Actions** tab.
2. Select **Build Tools Android APK and AAB**.
3. Choose **Run workflow** and run it on `main`, or push a change under `app/`.
4. Open the completed workflow run and download the artifacts:
   - `Tools-debug-APK` — installable debug APK.
   - `Tools-release-AAB-unsigned` — unsigned AAB for build testing only.

## Important signing note

The APK is a debug build and is signed with the temporary debug key generated by Android Gradle Plugin. The AAB is unsigned; it is not ready to upload directly to Google Play. For Play Store release, configure a protected release signing key in GitHub Actions secrets and sign the AAB, or use Play App Signing with a properly signed upload bundle.

## App identity

- App name: Tools
- Application ID: `com.parvez.tools`
- Minimum Android version: Android 6.0 (API 23)
- Version: 1.0.0 (versionCode 1)

Never commit a private signing keystore or its password to this repository.
